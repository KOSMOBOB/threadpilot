## 🚀 Быстрый старт

### 1. Запустите сервер
```bash
cd /path/to/threadpilot
npm start
```

### 2. Установите расширение в Chrome
1. Откройте `chrome://extensions/`
2. Включите **"Режим разработчика"**
3. Нажмите **"Загрузить распакованное расширение"**
4. Выберите папку `/path/to/threadpilot/extension`
5. Закрепите расширение на панели (📌)

### 3. Откройте Threads
1. Перейдите на **https://www.threads.com** (или threads.net)
2. Залогиньтесь в свой аккаунт
3. Кликните по иконке threadpilot
4. Убедитесь что статус **"бекенд доступен"** (зелёный)
5. Включите **"Агент активен"**

### 4. Откройте дашборд
Перейдите на **http://localhost:3000** — здесь вы увидите:
- Живую ленту с обрабатываемыми постами
- Аналитику в реальном времени
- Настройки конфигурации
- Расписание работы

## 📊 Статистика и аналитика

### Popup расширения (иконка в браузере)
Показывает текущую сессию:
- **Опубликовано**: сколько комментов оставлено сегодня
- **Пропущено**: сколько постов отсеяли фильтры
- **Сканировано**: всего обработано постов
- **Прогресс-бар**: визуализация дневного лимита (например, 12/35)

### Дашборд (http://localhost:3000)
Полная аналитика с фильтрацией:

#### Селектор периода (вверху блока "Сводка")
- **1 час** — последние 60 минут (разбивка по 10-минутным интервалам)
- **24 часа** — последние сутки (разбивка по часам)
- **7 дней** — последняя неделя (разбивка по дням)
- **30 дней** — последний месяц
- **Всё время** — вся история

#### Метрики
- **Опубликовано** — количество оставленных комментариев
- **Лайки** — суммарные лайки на ваших комментах (имитация)
- **Ответы** — суммарные ответы на ваши комментарии (имитация)
- **Конверсия** — процент опубликованных от сканированных постов

#### Графики
- **Активность по дням** — линейный график с тремя линиями:
  - Зелёная: опубликовано
  - Красная: пропущено
  - Синяя: лайки
- **Исходы сканирования** — donut chart (опубликовано/пропущено/кандидаты/в очереди)
- **Топ ниш** — горизонтальные бары с самыми популярными тегами
- **Последние комменты** — лента из 8 последних комментариев с метриками

#### Кнопка "Сброс"
- Обнуляет счётчики лайков и ответов
- Данные (посты и комментарии) остаются в базе
- Полезно для A/B тестов: сбросили → поменяли стиль → сравниваем

## ⏰ Расписание работы

### Зачем нужно
Threads отслеживает паттерны активности. Если вы комментируете 24/7 — это выглядит как бот. Расписание имитирует естественное поведение:
- Утром перед работой (6-9 AM EST)
- Вечером после работы (7-10 PM EST)
- Выходные дни (опционально)

### Как настроить

1. Откройте дашборд → левая колонка → блок **"Расписание работы"**
2. Поставьте галку **"включить работу по расписанию"**
3. Добавьте диапазоны времени:
   - Например: `06:00 — 09:00` и `19:00 — 22:00`
   - Можно добавить несколько диапазонов
4. Выберите **часовой пояс**:
   - `America/New_York` — США (Нью-Йорк, EST)
   - `America/Los_Angeles` — США (Лос-Анджелес, PST)
   - `America/Toronto` — Канада (Торонто)
   - `Europe/London` — Британия (Лондон)
   - `Australia/Sydney` — Австралия (Сидней)
5. Нажмите **"Сохранить расписание"**

### Рекомендуемое расписание для западной аудитории

**Вариант 1: Утро + Вечер (США Восточное побережье)**
```
06:00 — 09:00  (люди просыпаются, скроллят перед работой)
19:00 — 22:00  (вечерний отдых, максимальный engagement)
```

**Вариант 2: Три окна (покрытие всех зон США)**
```
07:00 — 09:00  (Восточное побережье утро)
12:00 — 14:00  (обеденный перерыв все зоны)
19:00 — 21:00  (Западное побережье вечер)
```

**Вариант 3: Консервативный (безопасный старт)**
```
08:00 — 10:00  (только утро, 2 часа в день)
```

### Как это работает
- Агент проверяет текущее время перед каждым комментарием
- Если время вне активных часов — пост пропускается с причиной "вне активных часов работы"
- В логе дашборда видно: "Пропускаю @nick: вне активных часов работы"

## 🎯 Настройка конфигурации

### Ниша (теги)
Список ключевых слов через запятую. Агент ищет посты где есть хотя бы одно из этих слов.

**Пример для демонстрационной ниши:**
```
support, reflection, growth, mindset, wellbeing, personal development,
self-care, journaling, daily practice, resilience, motivation,
clarity, habits, emotional balance, self-awareness
```

### Стоп-слова
Посты с этими словами пропускаются автоматически.

**Пример:**
```
crypto, bitcoin, nft, trump, politics, recipe, food, cooking, fitness, gym, 
workout, dropshipping, amazon fba, mlm, network marketing, link in bio, 
buy now, limited offer, giveaway, contest, win free, discount code
```

### Примеры стиля
5-10 фраз которые показывают LLM как писать. Чем больше примеров — тем точнее стиль.

**Пример для эмпатичного тона:**
```
felt this so hard 🥺
same rn honestly, this really resonated
you're not alone in this, promise
this hit different ngl
i've been there, sending love 🤍
how are you holding up today
that makes a lot of sense, thanks for sharing
```

### Параметры движка

**Человечность (0-100%)**
- 0% — формальный текст, без сленга и опечаток
- 50% — умеренный сленг, редкие опечатки
- 75% — разговорный стиль, сленг (rn, ngl, tbh), строчные буквы (рекомендуется)
- 100% — максимум неформальности, много опечаток

**Эмодзи (0-100%)**
- 0% — без эмодзи
- 30% — редко, в основном 🤍 и 🥺 (рекомендуется для healing ниши)
- 70% — часто, разные эмодзи
- 100% — эмодзи в каждом комментарии

**Лимит/день**
Максимум комментариев за сутки. Рекомендуется:
- **Неделя 1-2**: 15-20 (прогрев аккаунта)
- **Неделя 3-4**: 25-30 (стабильный режим)
- **Месяц 2+**: 35-50 (масштабирование)

**Скорость**
- **Медленно** (1500ms) — максимально безопасно, имитация вдумчивого чтения
- **Как человек** (950ms) — баланс скорости и естественности (рекомендуется)
- **Турбо** (500ms) — быстрая обработка, выше риск детекта

**Публикация**
- **Simulate** — комментарии записываются в базу, но не публикуются в Threads (для тестов)
- **Webhook** — отправляет готовый комментарий на ваш URL (для интеграции с автопостером)

**Фильтры**
- ☑ **Пропускать посты с медиа** — если включено, агент игнорирует посты с фото/видео
- ☑ **Пропускать мимо ниши** — если включено, агент комментирует только посты где есть теги из ниши

## 🧠 LLM-провайдер

### Локальный генератор (по умолчанию)
Работает без API-ключа. Использует шаблоны + humanize() для естественности.

**Плюсы:**
- Бесплатно
- Быстро
- Предсказуемо

**Минусы:**
- Ограниченный словарный запас
- Может повторяться

### LLM (OpenAI/OpenRouter/Ollama)
Генерирует уникальные комментарии через языковую модель.

**Как подключить:**
1. Поставьте галку **"использовать LLM"**
2. Введите **endpoint**:
   - OpenAI: `https://api.openai.com/v1`
   - OpenRouter: `https://openrouter.ai/api/v1`
   - Ollama (локально): `http://localhost:11434/v1`
   - LM Studio: `http://localhost:1234/v1`
3. Введите **API-ключ**
4. Введите **модель** (например, `gpt-4o-mini`, `claude-3-haiku`, `llama3`)
5. Настройте **temperature** (0.7-0.9 для креативности)
6. Отредактируйте **системный промпт** (опционально)
7. Нажмите **"Проверить соединение"**
8. Если всё ок — **"Сохранить"**

**Рекомендуемый системный промпт:**
```
You are commenting on Threads posts from a real person who is sharing a personal challenge. Write in casual supportive English, all lowercase, no final punctuation. Use mild slang (rn, ngl, tbh) and rare typos. 5-12 words max. No hashtags, no 'as an AI', no quotes around the reply. Never include links. Match the emotional tone of the post.
```

**Плюсы:**
- Уникальные комментарии каждый раз
- Лучшее понимание контекста
- Естественный язык

**Минусы:**
- Платно (OpenAI: ~$0.0001 за комментарий)
- Медленнее (1-2 сек на генерацию)
- Зависит от интернета

**Fallback:** Если LLM недоступен (ошибка/таймаут), агент автоматически переключается на локальный генератор.

## 🔄 Рабочий процесс

### Ежедневная рутина

**Утро (5 минут):**
1. Откройте дашборд
2. Проверьте статистику за вчера
3. Убедитесь что сервер запущен (`npm start`)
4. Откройте Threads, включите агента в расширении

**В течение дня:**
- Агент работает автоматически по расписанию
- Периодически проверяйте popup расширения (иконка в браузере)
- Смотрите на прогресс: сколько опубликовано, сколько осталось до лимита

**Вечер (5 минут):**
1. Откройте дашборд
2. Посмотрите аналитику за день
3. Проверьте последние комментарии
4. Если нужно — поправьте примеры стиля

### Еженедельная оптимизация

**Раз в неделю:**
1. Откройте аналитику за 7 дней
2. Посмотрите **"Топ ниш"** — какие теги дают больше всего кандидатов
3. Если конверсия низкая (<20%) — расширьте список тегов
4. Посмотрите **"Последние комменты"** — есть ли повторяющиеся фразы
5. Если есть повторы — добавьте больше примеров стиля
6. Проверьте CTR в профиль (через аналитику профиля)
7. Если CTR <1% — меняйте био профиля или примеры стиля

### A/B тесты

**Как тестировать разные стили:**
1. Запишите текущие метрики (опубликовано, лайки, CTR)
2. Нажмите **"Сброс"** в аналитике
3. Поменяйте примеры стиля (например, более эмпатичные)
4. Работайте 3-5 дней
5. Сравните метрики с предыдущим периодом
6. Оставьте лучший вариант

## ⚠️ Красные флаги (немедленно стоп)

### 1. Threads пишет "Your account is restricted"
**Что делать:**
- Остановите агента на 7 дней
- Пишите только руками (10-15 комментов/день)
- Снизьте лимит на 50% после возобновления

### 2. Комменты скрыты (не видны другим)
**Как проверить:**
- Откройте Threads с другого аккаунта (инкогнито)
- Найдите свои комменты
- Если их нет — это shadowban

**Что делать:**
- Остановите агента на 3-5 дней
- Снизьте скорость до "медленно"
- Уменьшите лимит до 10/день
- Добавьте больше вариативности в примеры стиля

### 3. CTR в профиль ниже 1%
**Возможные причины:**
- Скучное био профиля
- Непонятная ссылка (URL длинный или неочевидный)
- Комменты не цепляют

**Что делать:**
- Перепишите био (добавьте конкретику: "went through a difficult season")
- Используйте link shortener (bit.ly) для ссылки
- Поменяйте примеры стиля на более эмоциональные

### 4. Нет конверсий / продаж за несколько недель
**Возможные причины:**
- Проблема в самом листинге/лендинге (фото/описание/цена)
- Нецелевая аудитория
- Слишком мало трафика

**Что делать:**
- Проверьте аналитику профиля и страницы: views, favorites, conversion rate
- Оптимизируйте листинг/лендинг (фото, описание, оффер)
- Увеличьте лимит комментариев до 50/день
- Добавьте больше тегов в нишу

## 🛠 Troubleshooting

### "бекенд недоступен" в popup
**Причина:** Сервер не запущен

**Решение:**
```bash
cd /path/to/threadpilot
node kill-port.js
npm start
```

### "Content script не загружен"
**Причина:** Расширение не инжектится на страницу

**Решение:**
1. Откройте `chrome://extensions/`
2. Нажмите 🔄 на карточке threadpilot
3. Обновите страницу Threads (F5)

### Агент не комментирует
**Причина:** Возможно, вне активных часов или достигнут лимит

**Проверка:**
1. Откройте DevTools (F12) → Console
2. Ищите логи `[threadpilot]`
3. Если видите "вне активных часов работы" — проверьте расписание
4. Если видите "дневной лимит достигнут" — увеличьте лимит или подождите до завтра

### Комменты на русском
**Причина:** Языковой фильтр не работает

**Проверка:**
- Убедитесь что в `extension/content.js` есть функция `isEnglishPost()`
- Проверьте что посты содержат латиницу

### Мало кандидатов
**Причина:** Слишком узкая ниша или агрессивные фильтры

**Решение:**
- Расширьте список тегов
- Выключите "пропускать мимо ниши"
- Уберите часть стоп-слов
