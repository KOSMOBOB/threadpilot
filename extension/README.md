# 🧩 threadpilot · Chrome-расширение

Агент для автоматического комментирования в Threads с LLM-генерацией и аналитикой.

---

## 📦 Установка

### 1. Откройте Chrome
Перейдите на страницу расширений:
```
chrome://extensions/
```

### 2. Включите режим разработчика
Переключатель в правом верхнем углу: **"Режим разработчика"** → **ВКЛ**

### 3. Загрузите расширение
Нажмите **"Загрузить распакованное расширение"** и выберите папку:
```
/path/to/threadpilot/extension
```

### 4. Закрепите на панели
Нажмите на иконку пазла (🧩) в Chrome → найдите **threadpilot** → нажмите 📌

---

## 🚀 Использование

### 1. Запустите сервер
```bash
cd /path/to/threadpilot
npm start
```

### 2. Откройте Threads
Перейдите на:
- **https://www.threads.com** (основной домен)
- или **https://www.threads.net** (альтернативный)

### 3. Залогиньтесь
Войдите в свой аккаунт Threads.

### 4. Откройте popup расширения
Кликните по иконке threadpilot в панели Chrome.

### 5. Проверьте статусы
Должно быть:
- ✅ **Backend** — "доступен" (зелёный)
- ✅ **Страница** — "Threads" + домен (threads.com или threads.net)

### 6. Включите агента
Нажмите на переключатель **"Агент"** → он станет зелёным.

## 📊 Что показывает popup

### Статусы
- **Backend** — доступен ли локальный сервер (http://localhost:3000)
- **Страница** — находитесь ли вы на threads.com/threads.net

### Переключатель агента
- **Выключен** — расширение не работает
- **Активен** — расширение сканирует ленту
- **Работает...** — идёт обработка постов

### Прогресс сегодня
Прогресс-бар показывает:
```
12 / 35
```
Это значит: 12 комментариев опубликовано из дневного лимита 35.

### Статистика сессии
Три блока:
- **Опубл.** — опубликовано комментариев сегодня
- **Пропущ.** — пропущено фильтров сегодня
- **Сканир.** — всего обработано постов сегодня

### Кнопки
- **Открыть дашборд** — открывает http://localhost:3000 в новой вкладке
- **Открыть Threads** — открывает threads.com в новой вкладке
- **Сброс** — сбрасывает статистику сессии (дневная остаётся)

### Лог
Показывает последние действия агента:
- Сканирование постов
- Публикация комментариев
- Ошибки и предупреждения

## 🔄 Обновление расширения

Если вы изменили файлы расширения (manifest.json, content.js, popup.js и т.д.):

1. Откройте `chrome://extensions/`
2. Найдите **threadpilot**
3. Нажмите иконку 🔄 (reload) на карточке расширения
4. Обновите страницу Threads (F5)

## ⚙️ Настройка

Все настройки хранятся в дашборде (http://localhost:3000):
- Ниша (теги)
- Стоп-слова
- Примеры стиля
- Лимиты и скорость
- LLM-провайдер
- Расписание работы

Расширение автоматически подтягивает эти настройки при каждом запуске.

## 🛡 Безопасность

### Что расширение делает:
- Читает DOM страницы Threads (только на threads.com/threads.net)
- Отправляет посты на локальный сервер (localhost:3000)
- Инжектит комментарии в поля ввода
- Кликает по кнопкам "Ответить" и "Опубликовать"

### Что расширение НЕ делает:
- Не отправляет данные на внешние серверы (кроме localhost)
- Не читает ваши пароли или cookies
- Не модифицирует другие сайты
- Не устанавливает дополнительные расширения

### Как проверить код:
Все файлы открыты и доступны для чтения:
- `manifest.json` — описание расширения
- `content.js` — логика работы на странице
- `popup.html` + `popup.js` — интерфейс popup
- `background.js` — service worker

## 🐛 Troubleshooting

### "бекенд недоступен"
**Причина:** Сервер не запущен

**Решение:**
```bash
cd /path/to/threadpilot
npm start
```

### "content script не загружен"
**Причина:** Расширение не инжектится

**Решение:**
1. Откройте `chrome://extensions/`
2. Нажмите 🔄 на карточке threadpilot
3. Обновите страницу Threads (F5)

### "Не на Threads"
**Причина:** Вы не на threads.com/threads.net

**Решение:**
Перейдите на https://www.threads.com

### Агент не комментирует
**Возможные причины:**
1. Вне активных часов (проверьте расписание в дашборде)
2. Достигнут дневной лимит
3. Все посты отсеяны фильтрами

**Проверка:**
Откройте DevTools (F12) → Console → ищите логи `[threadpilot]`
