## 1. Threads Profile Setup

### ⚠️ Critical: Without proper profile, funnel won't convert

Your profile is the **landing page**. Comments drive traffic TO it.

### Recommended Setup (English):

**Option A — Personal Story:**
```
Name: Alex · personal journey 🤍
Bio:
shared my story and found a better way
now helping people through simple, practical steps
example product / link in bio 👇
Link: https://example.com/your-product
```

**Option B — Direct:**
```
Name: Emma · practical support
Bio:
built a simple system that helped me
after going through a hard season
check it out 👇
Link: https://example.com/your-product
```

**Option C — Soft:**
```
Name: Jade · gentle guidance
Bio:
from struggle to clarity
small steps that actually work
example product / link in bio 👇
Link: https://example.com/your-product
```

### Profile Photo:
- Clear, warm, approachable
- Smile or gentle expression
- Good lighting, neutral background
- NO logos, NO text overlays

### Pinned Post (create one):
Write a personal post about your healing journey (3-4 paragraphs):
- Where you were (toxic relationship, burnout)
- What you tried (therapy, books, etc.)
- What actually worked (journaling, specific practices)
- Why you created the journal
- End with: "if this resonates, the journal that saved me is in my bio 🤍"

## 2. Cultural Nuances by Country

### 🇺🇸 United States (40% of traffic)

**Tone:** Direct but warm, action-oriented

**Keywords that resonate:**
- "self-care", "boundaries", "therapy", "mental health matters"
- "you deserve better", "protect your peace"
- "healing is not linear"

**Avoid:**
- Overly formal language
- Being too reserved
- Long-winded explanations

**Example comments:**
```
i've been there, it gets better i promise 🤍
that sounds really hard, sending love
you're doing great even if it doesn't feel like it
boundaries changed everything for me
```

---

### 🇨🇦 Canada (25% of traffic)

**Tone:** Warm, polite, inclusive, non-confrontational

**Keywords that resonate:**
- "self-care", "wellness", "mental health"
- "be gentle with yourself"
- "you're not alone in this"

**Avoid:**
- Aggressive language
- Overly sales-y tone
- Being too direct about problems

**Example comments:**
```
healing takes time, be gentle with yourself
this takes courage, thank you for sharing
one day at a time, that's enough
you're not alone in this 🤍
```

---

### 🇬🇧 United Kingdom (20% of traffic)

**Tone:** Slightly more reserved, dry humor acceptable, less emotional

**Keywords that resonate:**
- "mental health", "wellbeing", "self-help"
- "it's a journey"
- "take it one step at a time"

**Avoid:**
- Overly emotional language
- Too many exclamation marks
- Being too "American" (overly enthusiastic)

**Example comments:**
```
been there, it's a proper journey innit
one day at a time, that's all you can do
journaling helped me no end
you're stronger than you think
```

**Note:** British audience is more skeptical of "woo" language. Keep it practical.

---

### 🇦🇺 Australia (15% of traffic)

**Tone:** Casual, laid-back, can use "mate" sparingly

**Keywords that resonate:**
- "mental health", "self-care", "wellbeing"
- "no worries", "take your time"
- "you got this"

**Avoid:**
- Too formal or stiff
- Overly serious tone
- Being too "precious" about feelings

**Example comments:**
```
been there mate, it gets easier
you got this, one day at a time
journaling saved me honestly
sending good vibes your way 🤍
```

## 3. Comment Strategy

### The 7 Post Types (Agent Auto-Detects):

| Type | Trigger | Response Style |
|------|---------|----------------|
| `howto` | "what to do", "how to heal", "help me" | Empathy + soft profile hint (2-3x/day max) |
| `breakup` | "toxic", "narcissist", "abuse", "divorce" | Pure empathy + "i've been there" |
| `burnout` | "burnout", "exhausted", "overwhelmed" | Validation + gentle practices |
| `pain` | general emotional pain | Support + "you're not alone" |
| `question` | any question mark | Engage with question back |
| `progress` | "finally", "healing", "better" | Celebrate genuinely |
| `default` | everything else | Short warm response |

### Comment Frequency:

**Week 1:** 15-20 comments/day (warm-up)  
**Week 2:** 25-30 comments/day  
**Week 3+:** 35-40 comments/day (max)

### Profile Hint Frequency:

**Maximum 2-3 times per day**, ONLY on posts that explicitly ask "what should I do?" or "how do I heal?"

Example:
```
journaling saved me honestly, i put together what worked in my bio
```

**NEVER** put links in comments. Threads hides them.

## 4. Product Listing Optimization

### Title (140 chars max):
```
Example Product Title | Practical Resource | Simple Step-by-Step Solution
```

### Tags (12 tags, use all):
```
example product
practical resource
personal growth
self care
daily practice
wellbeing
mindset
supportive tools
simple system
step-by-step guide
targeted audience
product landing page
```

### Description Structure:

**Paragraph 1 — Hook:**
```
If you're looking for a simple way to make progress, this product is designed for you.

It was created to help people move from feeling stuck to feeling clearer and more confident.
```

**Paragraph 2 — What's Inside:**
```
✨ Practical steps you can follow
✨ Clear guidance for everyday use
✨ Useful prompts or exercises
✨ Simple structure for steady progress
```

**Paragraph 3 — Who It's For:**
```
This product is for you if:
→ You want a practical path forward
→ You prefer simple, actionable guidance
→ You want something easy to start with
→ You value clarity and consistency
```

**Paragraph 4 — Social Proof:**
```
"This made things much easier for me. The structure helped me stay consistent." — Alex, USA

"Finally something clear and useful. It felt practical from the start." — Emma, UK
```

**Paragraph 5 — Call to Action:**
```
Start with one small step today.
Grab your copy and begin with a simple, practical approach.

🤍 Instant access
🤍 Easy to follow
🤍 Clear and useful structure
```

### Photos (7 photos):

1. **Main:** Product on clean background, good lighting
2. **Flat lay:** Product + pen + simple props
3. **Details:** Show key pages, features, or sections
4. **Lifestyle:** Person using it in a calm setting
5. **Preview:** Show digital or printed format
6. **Testimonial:** Quote from review overlaid on photo
7. **Bundle:** If you have multiple products, show them together

### Price Strategy:

**Digital:** $9.99 - $19.99 USD  
**Physical:** $19.99 - $39.99 USD (if you add later)

**Psychological pricing:**
- Use .99 endings
- Offer 10% off for first-time buyers
- Create bundle discounts if you add more products

**Month 4+:**
- Comments: 1200-1500

- Sales: 25-40
- Revenue: $800-1500

### Key Metrics to Track:

1. **Comments per day** (target: 35)
2. **Profile clicks** (check Threads analytics)
3. **Product views** (analytics dashboard)
4. **Conversion rate** (sales / profile clicks)
5. **Revenue per comment** (total revenue / total comments)

### Break-Even Analysis:

If your journal is $17.99:
- Platform fees: vary by provider
- Net profit: ~$15.49
- Break-even: 10-15 sales/month = $155-232/month

**Time to break-even:** 2-3 months with consistent effort

## 7. Troubleshooting

### "No one is clicking my profile"

**Possible causes:**
1. Profile bio is unclear
2. Profile photo is unappealing
3. Comments are too generic
4. Not commenting on the right posts

**Fix:**
- Rewrite bio to be more specific
- Update profile photo
- Make comments more personal
- Target posts with higher engagement

### "Getting clicks but no sales"

**Possible causes:**
1. Product photos are weak
2. Price is too high
3. Description doesn't convert
4. No social proof (reviews)

**Fix:**
- Improve listing photos
- Test lower price ($14.99)
- Rewrite description using framework above
- Ask friends/family to buy and review

### "Threads is limiting my account"

**Possible causes:**
1. Commenting too fast
2. Using same comment repeatedly
3. Getting reported

**Fix:**
- Reduce to 20 comments/day for 1 week
- Increase comment variety
- Never copy-paste exact comments
- Take 2-3 day break if limited

### "Agent is not working"

**Check:**
1. Server is running: `npm start`
2. Extension is loaded in Chrome
3. You're on threads.net (not instagram.com)
4. Backend URL is http://localhost:3000
5. Check browser console (F12) for errors
